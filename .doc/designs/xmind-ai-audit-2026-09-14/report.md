# XMind AI 脑图交互对照与实现审查

审查日期：2026-09-14 至 2026-09-15

## 1. 审查范围

本次使用用户已登录的 Chrome 会话观察 XMind Web 的 AI 脑图入口、新对话首页、提示词模板、上下文、推理模式和讨论模式；未向 XMind 提交任何 AI 请求，避免消耗点数或向第三方传输当前脑图内容。

实现目标不是复制 XMind 的专有源码或图形资产，而是在现有 simple-mind-map 编辑器、权限、版本和协作体系内复现其高价值产品模式：左侧持久 AI 工作台、右侧唯一脑图画布、底部统一输入器、可见的生成过程以及明确的应用/撤销边界。

## 2. 参考流程

1. 点击 AI 入口后，左侧打开约 500px 宽的非模态工作台，右侧继续显示当前脑图。
2. 新对话首页展示“今天想做点什么？”和四个任务模板。
3. 底部输入器持续可见，包含当前脑图上下文、附件入口、推理模式和发送操作。
4. 更多设置中可以进入讨论模式；讨论模式不修改当前脑图。
5. 生成期间，AI 会话保留在左侧，脑图变化在右侧持续出现。

## 3. 落地结果

### 3.1 页面结构与样式

- AI 容器由全屏弹窗改为 500px 左侧非模态抽屉，编辑器顶部和右侧脑图保留可见。
- 抽屉使用浅灰背景、白色任务卡、紫色 AI 强调色、圆角输入器和紧凑状态标识。
- 首页提供与参考流程一致的四个任务模板；点击模板会填入对应要求并选择匹配的脑图意图。
- 底部统一输入器整合当前脑图上下文、附件、任务设置、编辑/讨论切换、快速/均衡/深度模式、发送与取消。
- 生成开始后，右侧只显示一个权威实时草稿画布，避免旧实现中预览与当前画布竞争空间。
- 手机宽度下抽屉占满屏幕；任务运行中或草稿可用时可切换到全屏实时脑图，再返回 AI 对话，避免 500px 固定宽度造成横向溢出且不丢失生成过程。

实现截图：[新对话首页](./10-local-xmind-style-home.png)、[实时生成](./12-local-realtime-generation.png)、[结果就绪](./13-local-generation-ready.png)、[应用成功](./14-local-cloud-applied.png)、[编辑器最终结果](./15-local-editor-after-apply.png)。

### 3.2 AI 交互和安全边界

- 左侧会话流实时展示用户要求、任务状态、经过清洗的 Agent 事件、工具开始/完成/失败和脑图变化版本。
- 不展示模型隐藏思维链，只展示允许审计的结构化事件。
- 已完成任务支持同会话继续生成、失败重试、历史轮次切换和会话删除。
- 当前脑图、当前分支、选中节点、新建脑图和文件来源仍由同一上下文模型管理。
- Codex SDK、Claude Code SDK 和原生脑图 Agent 继续通过统一 manifest/adapter 契约注册；前端不写死提供商，后续 Agent 可按同一契约接入。
- “讨论模式”关闭所有应用、另存、替换和插入类操作；回答写入独立的纯文本 Response，不创建 Artifact 或 Proposal，也不会进入应用与撤销流程。
- 三种内置 Agent 共用紧凑、低噪声的语义脑图上下文：保留完整节点层级、标题、备注、链接和用例标签，移除 UID、样式与编辑器内部字段，并明确区分根主题（`depth=0`）和一级模块（`depth=1`）。
- 原生 Agent 为 Ollama 显式设置至少 16K 上下文窗口，并把输出 token 上限独立控制，避免较大脑图在模型默认 4K 上下文中被截断。
- 新会话创建时立即生成稳定标题；后续轮次保持标题不变，旧会话则从首条用户要求恢复标题，不再显示“未命名对话”。

### 3.3 应用可靠性修复

- 修复云端应用在事务回滚后访问已过期 ORM 实例导致的 `DetachedInstanceError` / `MissingGreenlet`。
- 修复抽屉层级低于编辑器顶部栏造成“新对话”点击穿透的问题；抽屉本身位于最高交互层，右侧画布仍保持可操作。

## 5. 可用性与无障碍检查

- 会话流使用 `aria-live="polite"`，状态和连接变化不会抢占当前朗读。
- 抽屉、实时画布、历史轮次和工具按钮具备可识别名称。
- Enter 发送、Shift+Enter 换行，并忽略中文输入法合成中的 Enter。
- 未确认差异时“应用”保持禁用，后端函数仍保留二次防御和焦点引导。
- 运行中禁用新对话和参数切换，提供独立取消按钮，防止同一任务产生并发写入。
- 支持 `prefers-reduced-motion`，窄屏改为单列布局。

## 6. 已知产品差异

- 未复制 XMind 的商标、图标资源、字体文件、点数系统和私有模型行为。
- 本项目已使用独立纯文本 Response 实现讨论模式；它与脑图 Artifact/Proposal 完全隔离，并继续接受统一结构、安全和长度校验。
- 本项目保留比参考产品更严格的差异确认、幂等恢复、协作栅栏、可审计事件和撤销能力。
