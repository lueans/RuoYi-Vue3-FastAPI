# XMind 全功能对标与脑图编辑器 UI 规划书

> 版本：V1.0（评审稿）
> 日期：2026-08-25
> 范围：脑图编辑详情页的顶部导航、左侧导航、右侧工具与 XMind 级功能补全
> 本轮约束：只做规划与 UI 设计，不修改业务代码

## 1. 结论摘要

当前编辑器已经具备一套可用的脑图内核：节点编辑、结构关系、图片/链接/附件/笔记/标签、搜索替换、画布筛选、样式、版本历史、保存恢复和实时协作都已存在。主要问题不是“功能太少”，而是功能入口分散：顶部、右侧抽屉和底部导航重复承担命令，且所有侧栏竞争同一个右侧 348 px 空间。

推荐将编辑器改造成稳定的三域工作台：

- 顶部只放文档状态、高频结构命令和协作/演示入口。
- 左侧只负责发现与导航：搜索/替换、大纲、笔记、标签筛选、评论、历史。
- 右侧只负责创建与属性：节点属性、结构、主题、标记、贴纸、插画、任务和 AI。
- 左右侧栏在桌面端可以同时打开，不再互相抢占状态；中央画布仍保持可编辑宽度。

与 XMind 的差距集中在评论体系、任务/Gantt、贴纸与插画、完整搜索选项、协作发布、AI、跨端空间与高级导出。建议按“信息架构底座 → 搜索评论 → 资源与任务 → 协作发布 → AI 与生态”的顺序补齐。

### 4.2 顶部命令栏

从左到右分为三个稳定区：

1. 文档区：应用标识、返回/菜单、标题、云端保存状态、协作者头像。
2. 编辑区：撤销、重做、主题、子主题、联系、概要、外框、更多。
3. 业务区：AI、甘特图、演示、评论、标记、分享、面板开关、头像。

规则：

- 文件导入导出、打印、快捷键等低频操作放入文件/更多菜单。
- 保存状态持续可见，只有异常时才出现带文字的重试动作。
- 评论显示未读数；分享是唯一高强调主按钮。
- 窗口不足时，编辑区先折叠为“编辑”下拉，业务区保留评论和分享。

## 6. 搜索、替换、筛选专项规划

### 6.1 搜索状态机

1. `⌘/Ctrl+F`：打开左侧搜索并聚焦输入框，不改变画布缩放与节点位置。
2. 输入后 150–250 ms 防抖，优先搜索当前已加载文档；超大文档再切服务端分页。
3. 结果点击：居中节点、选中、短暂高亮；不触发全量 `setData`。
4. Enter/Shift+Enter：循环下一个/上一个；结果计数为 `当前/总数`。
5. Esc：先退出结果选中，再关闭临时搜索；已固定的左栏只清空焦点。

### 6.2 替换安全规则

- 只读、归档或权限失效时隐藏替换动作。
- 单次替换立即进入撤销栈；全部替换先显示影响节点数和范围。
- 替换只修改节点文字，不修改标签名称、笔记或任务，除非用户在范围中显式勾选。
- 协作中替换以一次批量事务广播，避免每个字符形成独立版本和冲突提示。

### 6.3 筛选无感刷新

- 过滤前记录当前视口、缩放、选中节点和展开状态。
- 计算节点可见集合时同时计算边可见集合；只有两端都可见的边才渲染。
- 匹配节点及其祖先路径保留原坐标，不因节点减少而重新排版。
- 只更新可见性和命中态，不替换整棵树数据。
- 退出筛选恢复全部节点和原视口；筛选期间发生的内容编辑仍保留。

## 7. 评论与协作专项规划

### 7.1 评论对象

- 画布评论：锚定在世界坐标，可拖动锚点。
- 节点评论：锚定节点 UID，节点移动时自动跟随。
- 线程包含：创建人、参与人、消息、@、附件、已读游标、解决状态、置顶状态。

### 7.2 评论 UI

- 顶部“评论”显示未读角标并切换左侧评论模式。
- 画布锚点只显示头像/数字；点击后弹出线程浮层，并在左栏同步选中。
- 左栏提供未读、全部、已解决、仅我的线程四个筛选；支持日期/未读排序。
- 删除、解决、重开和移动锚点都进入审计记录，但不污染脑图内容版本。

### 7.3 协作冲突原则

- 云端版本是重新进入编辑时的唯一权威来源；退出前完成保存后清空当前脑图本地缓存。
- 首次加载期间不比较尚未完成同步的本地/云端快照，避免重复冲突提示。
- 内容冲突只在同一字段出现不可自动合并的并发写入时提示；视口、选中、侧栏和筛选属于个人状态，不参与冲突比较。

## 8. 数据与权限规划（不涉及本轮实现）

建议新增或明确以下领域模型：

| 模型 | 关键字段 | 权限/版本原则 |
| --- | --- | --- |
| 评论线程 | 文档、节点 UID/画布坐标、状态、置顶、创建人 | 可查看文档即可读；可评论权限独立配置 |

## 9. 实施路线图

### 阶段 A：信息架构底座（P0）

- 新编辑器壳：56 px 顶栏、双活动栏、可并存/可调宽左右面板、32 px 画布栏。
- 把现有搜索、替换、大纲、版本迁入左侧；属性、结构、主题、图标迁入右侧。
- 统一面板状态、快捷键、焦点管理和响应式规则。
- 保持现有保存、Yjs、筛选和节点内核逻辑不变，先完成 UI 迁移。

验收：现有功能零回归；1440 px 下双栏同时打开仍有 ≥520 px 画布；面板切换不重建脑图实例。

### 阶段 B：搜索、筛选、评论闭环（P0–P1）

- 搜索增加大小写、全字、范围；筛选支持笔记、标记、任务、优先级和淡化模式。
- 新增画布/节点评论、@、已读、解决、筛选、通知。
- 完善跨文件搜索和历史差异预览。

验收：10 万节点服务端搜索可分页；筛选不产生多余连线；评论定位准确且不进入内容冲突。

### 阶段 C：资源中心与专业脑图（P1）

- 标记、统一标签、贴纸、插画、最近资源和自定义资源组。
- 多画布、跨画布链接、更多结构、混合结构、编号、快速样式和自定义主题。
- 选中节点浮动工具条收敛全部高频内容插入。

验收：标记样式由统一定义直接引用；多标签/多标记不复制定义；资源面板搜索与虚拟滚动稳定。

### 阶段 D：任务、甘特图、演示和发布（P1–P2）

- To-Do、完整 Task、依赖、负责人和任务导出。
- 脑图与 Gantt 双向同步；演示自动路径和手动编排。
- 公开链接、密码、有效期、嵌入和团队分享。

验收：脑图/甘特修改同一任务字段不会双写冲突；权限在链接撤销后即时失效。

### 阶段 E：AI 与生态（P2–P3）

- AI 生成、扩写、改写、去重、重组与来源研究。
- 工作空间、收藏、外部云盘、Slack/邮件通知。
- AI 所有写操作先给出变更预览，并作为单个可撤销事务提交。

## 10. 非功能验收标准

| 维度 | 标准 |
| --- | --- |
| 性能 | 打开/关闭侧栏不重建脑图；筛选只改可见集合；拖拽/缩放保持 60 fps 目标 |
| 协作 | 个人视图状态不广播；内容写入按事务；断线重连不重复弹冲突 |
| 可访问性 | 图标按钮有可访问名称；键盘可达；焦点环可见；颜色不是唯一状态表达 |
| 一致性 | 默认控件高 32 px；正文 12–13 px；活动栏 48 px；同类面板标题和关闭规则一致 |
| 可恢复性 | 替换、批量修改、AI、任务/Gantt 操作均可撤销；版本恢复生成新版本 |
| 权限 | 只读状态不出现写操作；评论、任务、分享、发布分别校验权限 |
| 可观测性 | 保存、搜索、评论、同步、导出失败均有可重试状态与埋点 |

## 12. 本轮评审建议

请优先确认以下三个产品决策，确认后再进入实现设计：

1. 左侧是否固定承担“搜索/大纲/评论/历史”，右侧固定承担“属性/资源/任务/AI”。
