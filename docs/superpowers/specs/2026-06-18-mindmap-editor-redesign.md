# 脑图详情页重构设计 — XMind Pro 风格

> 日期：2026-06-18
> 状态：待实现

## 1. 概述

将脑图编辑器页面从当前的飞书风格重构为 XMind Pro 深色专业风格，包括：顶部工具栏三区重组、右侧属性面板重构（三种模式）、底部状态栏固定化、整体视觉系统升级。

## 2. 整体布局架构

### 2.1 布局结构

```
┌──────────────────────────────────────────────────────────────┐
│ ██ 深色顶部栏 48px ██                                        │
│ [←] 项目名 │ [↶↷][±节点][B][🎨] │ 💾 已保存 [🔗分享][⚙]    │
├──────────────────────────────────┬───────┬───────────────────┤
│                                  │ 图标  │                   │
│          画布 flex:1             │  栏   │  属性面板 280px   │
│       (面板展开时自动缩小)        │ 48px  │  (可折叠)        │
│                                  │       │                   │
├──────────────────────────────────┴───────┴───────────────────┤
│ 底部状态栏 32px (固定全宽)                                    │
│ [⌂][🔍][🖱][🗺] │ [👁/✏][⛶] │ 75% [🌙][▶][⋯]             │
└──────────────────────────────────────────────────────────────┘
```

### 2.2 核心布局变化

| 区域 | 当前 | 新设计 |
|------|------|--------|
| 顶部栏 | 白底 52px，工具混排 | 深色 48px，三区分离 |
| 右侧 | 56px 图标轨道覆盖画布 + 300px 浮动面板 | 48px 图标栏 + 280px 挤压面板 |
| 底部 | 浮动圆角按钮条 (fixed) | 固定全宽状态栏 32px |
| 画布 | 占满剩余空间 | flex:1，面板展开时自动缩小 |

### 2.3 侧边栏三种模式

| 模式 | 标识 | 行为 | 画布影响 |
|------|------|------|---------|
| **常驻 (pinned)** | 📌 | 图标栏 + 面板始终可见 | 画布持续缩小 336px (48 图标栏 + 280 面板 + 8 间距) |
| **隐藏 (hidden)** | 👁 | 完全隐藏，右边缘悬浮按钮打开 | 画布占满 |
| **自动 (auto)** | ⚡ | 选中节点自动展开面板，取消选中自动收起 | 动态缩小/恢复 |

- 默认模式：`auto`
- 用户在面板图标栏底部的模式切换按钮切换
- 模式选择持久化到 `localStorage`（`localConfig.sidebarMode`）

### 2.4 模式行为详细

**常驻模式 (pinned)：**
- 图标栏和面板始终可见
- 面板显示当前选中节点的属性（无选中时显示脑图全局设置）
- 点击图标栏项目切换面板内容
- 再次点击同一项不关闭（因为常驻模式不允许关闭）

**隐藏模式 (hidden)：**
- 图标栏和面板完全隐藏
- 画布右边缘显示半透明 `◀` 展开按钮
- 点击展开后临时显示面板（行为类似 auto，但不会因选中节点自动展开）
- 手动点击 `✕` 或 `◀` 关闭

**自动模式 (auto)：**
- 无选中节点时：只显示图标栏（48px）
- 选中节点时：自动展开属性面板（280px），显示该节点的样式属性
- 取消选中时：面板自动收起
- 用户点击图标栏其他项：切换面板内容（不关闭）
- 用户点击 `✕`：关闭面板并切回仅图标栏状态

### 4.2 属性面板 (280px 宽)

面板标题栏 40px：左侧面板名称（14px 白色粗体），右侧 `✕` 关闭 + `◀` 折叠到图标栏。

面板内容区可滚动，16px padding，根据选中项显示不同组件：

| 面板 | 组件 | 内容 |
|------|------|------|
| 节点样式 | `NodeStylePanel` | 填充、边框、文字、形状（替换现有 `Style.vue`） |
| 主题 | `ThemePanel` | 主题选择、自定义颜色（替换现有 `Theme.vue`） |
| 大纲 | `OutlinePanel` | 树形大纲 + 编辑（替换现有 `OutlineSidebar.vue`） |
| 结构 | `StructurePanel` | 布局类型选择（替换现有 `Structure.vue`） |
| 设置 | `SettingPanel` | 全局设置（替换现有 `Setting.vue`） |
| 版本历史 | `VersionPanel` | 版本列表 + 恢复（复用 `VersionHistory.vue`） |
| 协作者 | `CollaboratorPanel` | 协作管理（复用 `CollaboratorManager.vue`） |

> 范围校正：当前仓库不存在 `VersionHistory.vue`、`CollaboratorManager.vue` 和
> `ShareDialog.vue`。版本历史、协作者和分享入口不纳入本轮重构；在后端接口、权限模型和
> 对应组件另行设计并实现前，不渲染这些入口，也不创建空壳组件。

### 4.3 面板展开/收起动效

```css
/* 展开 */
.sidebar-panel {
  width: 0;
  opacity: 0;
  transition: width 300ms ease-out, opacity 200ms ease-out 100ms;
}
.sidebar-panel.open {
  width: 280px;
  opacity: 1;
}

/* 画布区域过渡 */
.canvas-area {
  transition: margin-right 300ms ease-out;
}
```

面板宽度变化会改变脑图容器尺寸，但不会触发 `window.resize`。`Edit.vue` 必须使用
`ResizeObserver` 监听实际画布容器，在尺寸变化时调用 `mindMap.resize()`；组件卸载时断开
observer。宽度动画期间由 observer 持续同步，不能只在动画结束时同步一次，否则动画中会
出现 SVG 尺寸、命中区域和中心位置不一致。

### 4.4 自动模式的节点选中行为

```
事件流：
1. 用户点击节点 → simple-mind-map 触发 `node_active(node, activeNodeList)` 事件
2. `Edit.vue` 原样转发：`bus.emit('node_active', node, activeNodeList)`
3. 监听器读取第二个参数；`activeNodeList.length > 0` 时调用 `actions.autoOpenSidebar('nodeStyle')`
4. 面板自动展开并显示节点样式
5. 用户点击画布空白处 → 事件参数为 `(null, [])`
6. 监听器读取第二个参数并调用 `actions.autoCloseSidebar()`
7. 面板自动收起
```

## 8. 状态管理变更

### 8.1 useStore.js 新增

```js
// state 新增；sidebarMode 只存放在 localConfig，禁止再创建顶层同名状态
{
  sidebarCollapsed: false,    // 面板是否折叠（仅 pinned/auto 模式有效）
}

// actions 新增
{
  setSidebarMode(mode)        // 设置侧边栏模式，持久化到 localStorage
  toggleSidebar()             // 切换面板展开/收起
  autoOpenSidebar(panelName)  // auto 模式下自动打开（由 node_active 触发）
  autoCloseSidebar()          // auto 模式下自动关闭（由取消选中触发）
}
```

### 8.2 localConfig 新增

```js
{
  sidebarMode: 'auto',        // 侧边栏模式
}
```

`store.localConfig.sidebarMode` 是模式的唯一数据源。`setSidebarMode()` 必须通过现有
`setLocalConfig()` 更新和持久化；所有组件均从 `store.localConfig.sidebarMode` 读取，避免
顶层 state 与持久化配置在刷新或重置后发生分叉。

## 9. 响应式适配

| 断点 | 行为 |
|------|------|
| > 1200px | 完整布局：工具栏全显示 + 面板正常展开 |
| 768-1200px | 中间工具区插入组/格式组收起进更多菜单 |
| < 768px | 面板改为覆盖式（不挤压），图标栏隐藏，底部状态栏横向滚动 |

## 10. 暗色模式兼容

当前系统已有 `isDark` 切换。新设计中默认即为深色 UI，画布区域可独立切换亮/暗。
- `isDark = true`：画布也变暗色（当前行为）
- `isDark = false`：画布白色，但工具栏/面板/状态栏保持深色（新行为）

即：UI 框架始终深色，`isDark` 只控制画布区域。

## 11. 不受影响的部分

- 脑图核心引擎 `simple-mind-map` 及其所有插件
- Yjs 实时协作逻辑
- 自动保存机制（2s 防抖）
- 右键菜单 `Contextmenu.vue`
- 所有弹出对话框（NodeImage, NodeHyperlink, NodeNote, NodeTag 等）
- 后端 API

默认主题的根节点字号保持引擎原值 16px。若详情页需要 20px，只能在详情页创建 MindMap
实例时通过页面级 `themeConfig.root.fontSize = 20` 覆盖，不能修改
`simple-mind-map/src/theme/default.js`，以免影响通用 MindMap 组件和已有脑图数据。
